Detecting Unusual Polling-Station Results with MultFourier

Charles Thraves, Pablo Rivas, Felipe Subiabre

Motivation

This vignette illustrates how MultFourier can be used to identify unusual outcomes in a collection of multinomial observations. The application analyzes results from polling stations belonging to the same polling location in the 2024 Chilean municipal election. Each polling location (local de votación) hosts several polling stations (mesas), each with its own ballot box and list of registered voters.

Within a polling location, registered voters are assigned to polling stations according to alphabetical order. If voter surname is unrelated to political preference, the underlying voting distribution should be broadly similar across stations in the same polling location. This structure provides a natural multinomial goodness-of-fit setting: we can estimate a reference probability vector from the remaining stations in the location, and then test whether the result observed at a given station is statistically compatible with that null distribution.

The example focuses on the Escuela Centenario polling location in the city of Iquique. This location comprises 15 polling stations, numbered 276 through 290. Most stations contain 400 registered voters, while the final two stations are smaller.

Leave-One-Out Reference Distribution

Let \(X_m = (X_{m1}, \ldots, X_{mK})\) denote the vector of observed counts at station \(m\), with total sample size \(N_m = \sum_{k=1}^K X_{mk}\).

To evaluate whether station \(m\) is compatible with the location as a whole without allowing an anomalous station to contaminate its own reference distribution, we estimate the null probability vector using a leave-one-out scheme:

\[ \widehat p_k^{(-m)} = \frac{\sum_{j \neq m} X_{jk}}{\sum_{j \neq m} N_j}, \qquad k = 1, \ldots, K. \]

Under this formulation, station \(m\) contributes zero weight to its own reference vector \(\widehat{\mathbf{p}}^{(-m)}\).

loo_p <- sapply(
  seq_len(ncol(votes)),
  function(m) {
    other_counts <- rowSums(votes[, -m, drop = FALSE])
    other_counts / sum(other_counts)
  }
)

rownames(loo_p) <- rownames(votes)
colnames(loo_p) <- colnames(votes)

Detailed Analysis of Station 278

We model the counts at station 278 as

\[ X_{278} \sim \mathrm{Multinomial}\left(N_{278} = 400, \; \boldsymbol{\pi}\right), \]

and test whether the vote shares \(\boldsymbol{\pi}\) at this station match those of the rest of the location:

\[ \begin{aligned} H_0 &: \; \boldsymbol{\pi} = \widehat{\mathbf{p}}^{(-278)}, \\ H_1 &: \; \boldsymbol{\pi} \neq \widehat{\mathbf{p}}^{(-278)}. \end{aligned} \]

We use the log-likelihood ratio statistic, which measures how far the observed vote shares are from the reference shares:

\[ G^2(x) = 2 \sum_{k=1}^{K} x_k \ln\left(\frac{x_k}{N_{278}\, \widehat p_k^{(-278)}}\right), \]

where \(x = (x_1, \ldots, x_K)\) are the observed counts and terms with \(x_k = 0\) are taken as zero. The \(p\)-value is the probability, under \(H_0\), of a value of the statistic at least as large as the observed one:

\[ p = \mathbb{P}_{H_0}\left(G^2(X_{278}) \ge G^2(x)\right). \]

Other statistics are compared in a later section.

We first compare observed counts with expected counts under \(\widehat{\mathbf{p}}^{(-278)}\):

Fourier inversion: pval_fourier()

The main method of MultFourier is pval_fourier(). It writes the exact \(p\)-value as a Fourier series and sums it until a stopping rule is met. The partial sums are accelerated by extrapolation, and the summation stops as soon as either B consecutive terms are each smaller than rel_eps / B relative to the partial sum, or the extrapolated values vary by at most a relative rel_eps over the last half of the terms. Throughout this vignette we use the defaults B = 50 and rel_eps = 1e-3. The result is therefore an approximation whose accuracy depends on how fast the series converges; rel_eps sets how stable the sum must be, not a bound on its error.

fit_278 <- pval_fourier(
  x = votes[, "278"],
  p = loo_p[, "278"]
)

The returned multfourier object is a list; its main fields are:

  • fit_278$pval: computed \(p\)-value (\(\approx\) 9.2 × 10−33).
  • fit_278$stat: test statistic used ("Log-Likelihood Ratio").
  • fit_278$n_terms: number of Fourier series terms evaluated (206 here).
  • fit_278$time: total execution time in seconds (0.039 s here).
  • fit_278$method: computational method used ("fourier").
  • fit_278$status: completion status ID (0 indicates that the stopping rule was met).

The remaining fields (the exponential tilt gamma, the period half-width W and four convergence diagnostics such as err_rel_ext) are described in ?pval_fourier.

A \(p\)-value of order \(10^{-33}\) indicates that the pattern observed at station 278 would be extremely unlikely under the null model.

Exact computation: pval_exact()

The multinomial support for station 278 contains

\[ \binom{N + K - 1}{K - 1} = \binom{400 + 6 - 1}{6 - 1} = \binom{405}{5} = 88,978,137,003 \approx 8.9 \times 10^{10} \]

outcomes. pval_exact() does not enumerate them one by one. It first computes, by dynamic programming, the smallest and largest value that the remaining part of the statistic can take for every number of categories and voters still to be assigned. It then assigns the counts one category at a time. When these bounds show that every completion of a partial assignment is at least as extreme as the observed outcome, the probability of that whole branch is added at once; when they show that none is, the branch is discarded. Only branches that can fall on either side of the observed value are explored further. The result is the exact \(p\)-value, and the computation remains feasible here even though the support is large:

exact_fit_278 <- pval_exact(
  x = votes[, "278"],
  p = loo_p[, "278"]
)

exact_fit_278$pval
#> [1] 9.201581e-33

On two threads (the default) it takes 31 s, against 0.039 s for pval_fourier(), and the relative difference between the two \(p\)-values is 3.3 × 10−4. The number of branches that must be explored, and hence the cost of pval_exact(), still grows quickly with the number of categories \(K\) and the sample size \(N\), which is where pval_fourier() is needed.

Automatic choice: pval_flexible()

pval_flexible() chooses between the two methods based on the size of the support: below a cutoff of \(\log_{10}(\text{support}) = 10\) it computes the exact \(p\)-value, and above it uses Fourier inversion. The cutoff is deliberately conservative, because the cost of pval_exact() depends on the observed counts and is highest for extreme outcomes like this one. For station 278, \(\log_{10}(\text{support}) \approx 10.95\), so it uses pval_fourier():

pval_flexible(
  x = votes[, "278"],
  p = loo_p[, "278"]
)$method
#> [1] "fourier"

Screening All Polling Stations

We now apply pval_fourier() to all 15 stations in Escuela Centenario, each against its own leave-one-out reference vector, and check its results against the exact \(p\)-values from pval_exact(). The data are used as they are, so the comparison covers the instance actually being analyzed, including the extreme tail at station 278.

Because the \(p\)-values span more than 30 orders of magnitude, we compare the two methods through the relative error \(|\hat p_{\text{Fourier}} / p_{\text{Exact}} - 1|\) rather than the absolute difference, which would be uninformative for small \(p\)-values.

p_fourier_all <- sapply(colnames(votes), function(m) {
  pval_fourier(votes[, m], loo_p[, m])$pval
})

p_exact_all <- sapply(colnames(votes), function(m) {
  # Station 278 was already computed above

Comparing Multinomial Test Statistics

MultFourier supports several classic statistics. All of them test the same hypotheses \(H_0\) and \(H_1\) stated above for station 278; they differ in how they order the possible outcomes from least to most extreme, and therefore in which outcomes count as “at least as extreme” as the observed one.

For a station with observed counts \(x = (x_1, \ldots, x_K)\), total \(N = \sum_k x_k\) and null probabilities \(p = (p_1, \ldots, p_K)\) (here \(\widehat{\mathbf{p}}^{(-m)}\)), the multinomial sample space is

\[ \Omega_N = \left\{ y \in \{0, 1, \ldots, N\}^K : \sum_{k=1}^{K} y_k = N \right\}, \]

and the probability of an outcome \(y \in \Omega_N\) under \(H_0\) is

\[ P(y) = \frac{N!}{y_1! \cdots y_K!} \prod_{k=1}^{K} p_k^{y_k}. \]

For a statistic \(T\) in which larger values are more extreme, the \(p\)-value is

\[ p = \sum_{y \in \Omega_N} P(y) \, \mathbf{1}\left\{ T(y) \ge T(x) \right\}. \]

Probability Mass Function ("pmf"). Outcomes are ordered by their own probability under \(H_0\): an outcome is at least as extreme as \(x\) when it is at most as probable. The \(p\)-value is

\[ p_{\text{PMF}} = \sum_{y \in \Omega_N} P(y) \, \mathbf{1}\left\{ P(y) \le P(x) \right\}. \]

Pearson’s Chi-Square ("chi2"). Outcomes are ordered by the squared distance between observed and expected counts, scaled by the expected counts:

\[ X^2(y) = \sum_{k=1}^{K} \frac{(y_k - N p_k)^2}{N p_k}, \qquad p_{X^2} = \sum_{y \in \Omega_N} P(y) \, \mathbf{1}\left\{ X^2(y) \ge X^2(x) \right\}. \]

Log-Likelihood Ratio ("llr"). The statistic \(G^2\) defined above for station 278, with \(p_{G^2}\) given by the same formula with \(T = G^2\).

Power Divergence ("pd"). The family of Cressie and Read (1984), indexed by a real parameter \(\lambda\):

\[ 2 I^{\lambda}(y) = \frac{2}{\lambda(\lambda + 1)} \sum_{k=1}^{K} y_k \left[ \left( \frac{y_k}{N p_k} \right)^{\lambda} - 1 \right], \qquad \lambda \neq 0, -1, \]

with the values at \(\lambda = 0\) and \(\lambda = -1\) defined as limits. The family contains Pearson’s statistic (\(\lambda = 1\)) and the log-likelihood ratio (\(\lambda \to 0\)). We use \(\lambda = 2/3\), the value recommended by Cressie and Read, which lies between the two.

test_specs <- list(

At this station, for PMF and LLR the Fourier series converges in a few hundred terms and agrees with the exact value. For Pearson’s chi-square and the power divergence it does not converge, and raising max_terms does not fix this: with 100,000 terms the chi-square result even becomes negative. The reason is structural. Pearson’s statistic is \(X^2 = \sum_k x_k^2 / (N p_k) - N\) with integer counts \(x_k\), so its values lie close to a lattice; the terms of the Fourier series then recur instead of cancelling, and the truncated sum does not settle. The power divergence with \(\lambda = 2/3\) behaves similarly at this station. In practice, check the status of every pval_fourier() result. When it is not 0, use pval_exact() if the instance is tractable, or a statistic such as LLR or PMF, for which the series converges.

Using the exact values for the two non-converged cells, all four statistics flag station 278, with \(p\)-values between 9.2 × 10−33 and 1.6 × 10−20. At this station, the detection of the anomaly does not depend on the statistic, although the size of the \(p\)-value varies by about 12 orders of magnitude.

Methodological Scope and Limitations

When interpreting these results, three methodological aspects must be kept in mind:

  1. Plug-in estimation: The leave-one-out probability vector \(\widehat{\mathbf{p}}^{(-m)}\) is estimated from data and then treated as known by pval_fourier(). The resulting numbers should strictly be interpreted as plug-in goodness-of-fit \(p\)-values.
  2. Nature of the anomaly: A vanishingly small \(p\)-value indicates that station 278 is highly incompatible with the assumption that all stations share a common multinomial distribution. It does not identify the cause of the discrepancy (e.g. data-entry error, transcription error, or genuine localized demographic differences).
  3. Multiple testing: When screening many stations, a multiple-testing correction (e.g. Bonferroni or Benjamini-Hochberg) should be applied over the full set of stations screened. For station 278 the conclusion does not depend on it: even a Bonferroni correction over tens of thousands of stations gives a threshold of order \(10^{-6}\), far above \(p \approx 10^{-33}\).

Summary

This example demonstrates a workflow for analyzing grouped multinomial counts:

  1. Visualize proportions across groups to detect visible deviations.
  2. Construct leave-one-out reference probabilities to prevent circular influence.
  3. Compute multinomial \(p\)-values using pval_fourier(), checking its status and falling back to pval_exact() when the series does not converge.
  4. Compare multiple statistics ("llr", "pmf", "chi2", "pd") to check that the conclusion does not depend on the choice of statistic.
