Detecting Unusual Polling-Table Results with MultFourier

Charles Thraves, Pablo Rivas, Felipe Subiabre

Motivation

This vignette illustrates how MultFourier can be used to identify unusual outcomes in a collection of multinomial observations. The application analyzes results from polling tables belonging to the same polling location in the 2024 Chilean municipal election.

Within a polling location, registered voters are assigned to polling tables approximately according to alphabetical order. If voter surname is unrelated to political preference, the underlying voting distribution should be broadly similar across tables in the same location. This structure provides a natural multinomial goodness-of-fit setting: we can estimate a reference probability vector from the remaining tables in the location, and then test whether the result observed at a given table is statistically compatible with that null distribution.

Data: Escuela Centenario, Iquique

The example focuses on the Escuela Centenario polling location in Iquique. This location comprises 15 polling tables, numbered 276 through 290. Most tables contain 400 registered voters, while the final two tables are smaller.

Leave-One-Out Reference Distribution

Let \(X_m = (X_{m1}, \ldots, X_{mK})\) denote the vector of observed counts at table \(m\), with total sample size \(N_m = \sum_{k=1}^K X_{mk}\).

To evaluate whether table \(m\) is compatible with the location as a whole without allowing an anomalous table to contaminate its own reference distribution, we estimate the null probability vector using a leave-one-out scheme:

\[ \widehat p_k^{(-m)} = \frac{\sum_{j \neq m} X_{jk}}{\sum_{j \neq m} N_j}, \qquad k = 1, \ldots, K. \]

Under this formulation, table \(m\) contributes zero weight to its own reference vector \(\widehat{\mathbf{p}}^{(-m)}\).

loo_p <- sapply(
  seq_len(ncol(votes)),
  function(m) {
    other_counts <- rowSums(votes[, -m, drop = FALSE])
    other_counts / sum(other_counts)
  }
)

rownames(loo_p) <- rownames(votes)
colnames(loo_p) <- colnames(votes)

# Reference distribution for table 278

Detailed Analysis of Table 278

For table 278, the null hypothesis posits:

\[ X_{278} \sim \mathrm{Multinomial}\left(N_{278} = 400, \; \widehat{\mathbf{p}}^{(-278)}\right). \]

We first compare observed counts with expected counts under \(\widehat{\mathbf{p}}^{(-278)}\):

Screening All Polling Tables

We now iterate over all 15 tables in Escuela Centenario. Each table is evaluated against its own leave-one-out reference distribution:

Comparing Multinomial Test Statistics

MultFourier supports several classic statistics to partition and order the multinomial sample space:

  1. Probability Mass Function ("pmf"): The exact multinomial point mass \(\mathbb{P}(X = x)\). Outcomes with probability less than or equal to the observed outcome form the rejection region.
  2. Pearson’s Chi-Square ("chi2"): Standard \(\sum (O_k - E_k)^2 / E_k\) discrepancy.
  3. Log-Likelihood Ratio ("llr"): \(G^2 = 2 \sum O_k \ln(O_k / E_k)\), standard for likelihood ratio tests.
  4. Power-Divergence Family ("pd"): Cressie & Read (1984) family parameterized by \(\lambda \in \mathbb{R}\). We use \(\lambda = 2/3\), a recommended choice balancing Pearson (\(\lambda = 1\)) and LLR (\(\lambda \to 0\)).
test_specs <- list(
  "PMF"                   = list(stat = "pmf"),
  "Pearson (Chi2)"        = list(stat = "chi2"),
  "Log-Likelihood Ratio"  = list(stat = "llr"),
  "Power Divergence (2/3)"= list(stat = "pd", lambda = 2/3)
)

p_by_test <- sapply(
  test_specs,
  function(spec) {
    sapply(
      colnames(votes),
      function(m) {
        args <- list(x = votes[, m], p = loo_p[, m], stat = spec$stat)
        if (!is.null(spec$lambda)) args$lambda <- spec$lambda
        fit <- do.call(pval_fourier, args)
        fit$pval
      }
    )
  }
)

comparison <- data.frame(
  Table = colnames(votes),

Methodological Scope and Limitations

When interpreting these results, two methodological aspects must be kept in mind:

  1. Plug-in estimation: The leave-one-out probability vector \(\widehat{\mathbf{p}}^{(-m)}\) is estimated from data and then treated as known by pval_fourier(). The resulting numbers should strictly be interpreted as plug-in goodness-of-fit \(p\)-values.
  2. Nature of the anomaly: A vanishingly small \(p\)-value indicates that table 278 is highly incompatible with the assumption that all tables share a common multinomial distribution. It does not identify the cause of the discrepancy (e.g. data-entry error, transcription error, or genuine localized demographic differences).
  3. Multiple testing: When screening many tables simultaneously, family-wise error rate or false discovery rate corrections (e.g. Bonferroni or Benjamini-Hochberg) should be applied.

Summary

This example demonstrates a clean workflow for analyzing grouped multinomial counts:

  1. Visualize proportions across groups to detect macroscopic deviations.
  2. Construct leave-one-out reference probabilities to prevent circular influence.
  3. Compute exact multinomial \(p\)-values using pval_fourier().
  4. Compare multiple statistics ("llr", "pmf", "chi2", "pd") to confirm robustness.
